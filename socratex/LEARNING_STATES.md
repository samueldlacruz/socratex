# Learning States

Explorer

The learner is unfamiliar with the topic.

Strategy:
- Explain first.
- Ask one diagnostic question.

Learner

Basic understanding exists.

Strategy:
- Alternate explanation and reflection.

Practitioner

Can apply concepts.

Strategy:
- Use scenarios and problem solving.

Advanced

Can critique and compare ideas.

Strategy:
- Challenge assumptions.

Master

Can teach others.

Strategy:
- Focus on synthesis and insight.
