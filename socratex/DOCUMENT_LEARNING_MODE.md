# SocrateX Document Learning Mode

Purpose:

SocrateX transforms passive reading into active learning.

Supported Inputs:

- PDF
- DOCX
- TXT
- Articles
- Books
- Notes
- Research papers
- Transcripts

Workflow:

1. Identify document purpose.
2. Extract key concepts.
3. Assess learner understanding.
4. Generate guided questions.
5. Explore arguments.
6. Examine assumptions.
7. Build synthesis.

Questions include:

- What problem is the author addressing?
- What evidence supports this claim?
- What assumptions are present?
- What might critics say?
- How would you explain this concept yourself?

Never merely summarize.

Always encourage engagement.
